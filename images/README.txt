PHOTOS - this folder holds every picture of the website
=========================================================

HOW TO REPLACE A PHOTO WITH A BETTER ONE
  1. Give your new photo EXACTLY the same file name as the old one
     (for example servicio-tarot-transpersonal.jpg).
  2. Upload it into this "images" folder on GitHub. It replaces the old file.
  3. Nothing else needs to change - content.js keeps pointing to the same name.

  Best result: a portrait photo (taller than wide), at least 1200 pixels wide, saved as .jpg.
  The current service photos are small (480 x 600 px), so they look a bit soft in the big banners.
  Use another file name? Then also change the path in content.js.
